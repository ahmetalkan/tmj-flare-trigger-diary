# Jaw-pain flare diary: food, stress, posture and clenching

A jaw-pain flare diary covering food, stress, posture and clenching, with NIDCR and MedlinePlus TMD pages.

This is a free, standalone mini-resource. The live HTML page is intended to be served from:

- Render: `https://tmj-flare-trigger-diary.onrender.com/`
- GitHub Pages: `https://ahmetalkan.github.io/tmj-flare-trigger-diary/`

It cites public pages on [tmjspecialistguide.com](https://tmjspecialistguide.com/) and official reference sources listed at the bottom of the page. Nothing here is a substitute for advice from a qualified professional.
